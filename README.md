# The Comfort Table

An editorial, interactive comfort-food landing page built for DEV's Frontend Challenge: Comfort Food Edition.

## Concept
Comfort food is more than a recipe: it is memory, ritual, timing, place and the people around the table. The primary experience turns that idea into a small interactive story.

## Features
- Responsive mobile/tablet/desktop layout
- CSS-generated hero food illustration
- Interactive comfort finder
- Semantic HTML
- Keyboard-visible focus states
- `aria-pressed` controls and `aria-live` result updates
- Reduced-motion support
- No external runtime dependencies
- Touch-friendly controls
- No stock imagery

## Pages
- `/` — Perfect Landing submission
- `/css-art.html` — CSS Art companion submission

## Local run
Open `index.html` directly or use any static HTTP server.

## Deployment
Designed for static deployment on Vercel, GitHub Pages, Netlify or Cloudflare Pages.
